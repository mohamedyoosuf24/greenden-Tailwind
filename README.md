# 🌐 Multi-Page Website Using HTML & Tailwind CSS

## 📌 Project Overview

This project is a modern and user-friendly multi-page website developed using **HTML5 and Tailwind CSS**. The main objective of this project is to create a clean, attractive, and well-structured website with multiple pages and an easy navigation experience.

The website includes different sections such as a Home Page, Product Page, and Contact Page. Each page is designed with a simple layout, consistent styling, and a user-friendly interface.

Tailwind CSS is used to style the website with utility classes, making the design process easier, faster, and more flexible.

## 🚀 Features

- **Home Page:** A clean and attractive landing page that introduces the website and provides easy navigation to other sections.
- **Product Page:** Displays product-related information in an organized and structured layout.
- **Contact Page:** Includes a contact form with input fields for users to enter their details and send inquiries.
- **Navigation Bar:** Provides easy navigation between different pages of the website.
- **Responsive Styling:** Uses Tailwind CSS utility classes to create flexible layouts for different screen sizes.
- **Consistent Design:** Maintains a clean and professional appearance across all pages.
- **Reusable Styling:** Uses Tailwind CSS classes to reduce the need for writing separate CSS styles.

## 💻 Pages Description

## ⚙️ How to Run the Project

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Install the required dependencies using:

```bash
npm install
```

4. Run the Tailwind CSS build command configured in `package.json`.
5. Open `index.html` in your browser to view the website.
